# Overheat Detector with Auto Cut-Off System

A cost-effective overheat detection and automatic power cut-off system designed using LM35 temperature sensor and LM358 operational amplifier.

## Overview
This system continuously monitors ambient temperature and triggers a relay-based power cut-off when the temperature exceeds a preset threshold, preventing overheating and potential damage to electronic devices.

## Features
- Automatic temperature monitoring
- Threshold-based shutdown
- Relay-controlled power cut-off
- Hardware implementation

## Components Used
- LM35 Temperature Sensor
- LM358 Operational Amplifier
- BC549 Transistor
- SPDT Relay
- Resistors and Capacitors

## Applications
- Home appliances
- Industrial equipment
- HVAC systems
- Fire safety systems
